# KhiCAS 优化版 · 真机安装与测试指南

> 目标设备:fx-CG50(用户已装 KhiCAS 1.7.0 英文版)
> 产物版本:优化构建(CI 构建 #7 成功)

## 📦 需要复制的文件

| 文件 | 来源 | 大小 | 说明 |
|---|---|---|---|
| `khicas50.g3a` | `D:\GitHub\khicas-opt\dist\` | 1.9MB | 主 Add-in(英文版) |
| `khicas50.ac2` | `D:\GitHub\khicas-opt\dist\` | 2.4MB | 第二段(CAS 引擎) |

## 🚀 安装步骤

1. 计算器**关机状态**下,用 Micro-USB 数据线连接电脑
2. 计算器按 **F1**(进入 USB 存储模式),电脑出现 U 盘
3. 把两个文件复制到**计算器根目录**(不是子文件夹)
4. 安全弹出 USB,计算器自动退出
5. 主菜单(Main Menu)应出现新的 KhiCAS 图标(黑底 χ 标志)

> ⚠️ 若提示空间不足:先删除旧版 KhiCAS(.g3a 和 .ac2 都删)
> ⚠️ 若主菜单仍是旧图标:说明旧版本未删除,确认删除旧的 khicas 文件

## 🧪 测试清单

### 1. 启动与图标(1 分钟)
- [ ] 主菜单新图标:黑底(未选中)/ 蓝底(选中),χ 标志,带阴影
- [ ] 启动 KhiCAS 正常进入

### 2. 帮助语言(2 分钟)
- [ ] 输入 `factor(x^2-1)` 后按 `SHIFT` + `HELP`(或 `?` 命令)查看帮助
- [ ] 重点检查之前有法语残留的命令:`Airy_Ai`、`circle`、`multinomial`、`isosceles_triangle`
- [ ] 确认帮助为全英文

### 3. 基准测试(3 分钟)
在 KhiCAS 中运行:
```
read("bench.xws")
```
或手动粘贴 `bench/bench.xws` 里的命令。记录各命令耗时。

**速度对比基准(记录耗时)**:`factor(2^127-1)`、`isprime(2^521-1)`、`factor(x^50-1)`、`integrate(ln(x)^5,x)`、`inv(randmatrix(30,30))`、`expand((x+y+z)^20)`

> 可在旧版 KhiCAS 上先跑一遍同样命令,得到对比基线

### 4. 稳定性(5 分钟)
- [ ] 运行大计算(如 `factor(2^1000-1)` 或 `expand((x+y+z)^50)`)
- [ ] 计算中途按 **AC** 中断 3 次
- [ ] 确认:中断后返回正常,无内存溢出、无重启
- [ ] 中断后检查变量/会话仍在(不需要 Delete Section)

### 5. 画图功能
- [ ] `plot(sin(x))` 进入画图
- [ ] 按 F1 看帮助、F2/F3/F4 试跟踪模式、XTT 看曲线信息(详见 docs/画图操作速查.md)

## 🔍 遇到问题时

| 现象 | 处理 |
|---|---|
| 主菜单无新图标 | 检查文件是否在根目录;删除旧版重试 |
| 启动卡死/黑屏 | 长按 AC 重启;确认 g3a+ac2 两个文件都完整 |
| 帮助仍有法语 | 反馈具体命令名,重新生成帮助文件 |
| 基准结果异常慢 | 反馈耗时,考虑扩大 -O2 模块范围 |
| 中断后崩溃 | 反馈操作步骤,检查 patch/03-ac-break-hardening 是否需应用 |
