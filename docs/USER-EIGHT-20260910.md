## 原始输入与数学参考答案

以下是独立推导的参考答案，不代表程序都已给出。

1. `integrate(x^5*(1-x^3)^50, x, 0, 1)`
   - 参考及实际结果：`1/7956`。令 `u=x^3`，积分为 `B(2,51)/3`。
2. `integrate((x^2-1)/((x^2+1)*sqrt(x^4+1)), x)`
   - 参考：`-asin(sqrt(2)*x/(1+x^2))/sqrt(2)+C`，实数 `x`。
   - 实际：`integrate((1+2/(-x^2-1))/sqrt(x^4+1),x)`。
   - 令 `u=sqrt(2)*x/(1+x^2)` 后利用 `sqrt(1-u^2)=sqrt(x^4+1)/(1+x^2)`。
3. `integrate(x*sin(x)/(1+cos(x)^2), x, 0, pi)`
   - 参考：`pi^2/4`。反射 `x -> pi-x` 后两式相加，再令 `u=cos(x)`。
   - 实际：在 `pi/2` 分段后，两个积分仍未求出。
4. `simplify(integrate(1/(sin(x)^4+cos(x)^4), x))`
   - 局部原函数参考：`atan(tan(2*x)/sqrt(2))/sqrt(2)+C`。
   - 实际原函数较长，原样保存于 JSON 报告，求导后与被积函数精确一致。
   - 反正切/正切表示需要按连续区间处理分支，不能未经衔接跨分支用端点相减。
5. `simplify(integrate((1+x^(1/4))^(1/3)/sqrt(x), x))`
   - 参考：`12/7*(1+x^(1/4))^(7/3)-3*(1+x^(1/4))^(4/3)+C`，实数域 `x>0`。
   - 实际：`(12*(x^(1/4)+1)^(1/3)*sqrt(x)+3*(x^(1/4)+1)^(1/3)*x^(1/4)-9*(x^(1/4)+1)^(1/3))/7`。
6. `integrate(ln(1+x)/(1+x^2), x, 0, 1)`
   - 参考及实际：`pi*ln(2)/8`。
7. `integrate(sin(x)^3/x, x, 0, +infinity)`
   - 参考及实际：`pi/4`，条件收敛。用 `sin(x)^3=(3*sin(x)-sin(3*x))/4` 和 Dirichlet 积分。
8. `integrate(x^2/(exp(x)+exp(-x)+2), x, -infinity, +infinity)`
   - 参考：`pi^2/3`。偶函数在正半轴展开为指数级数，积分为
     `4*sum((-1)^(n-1)/n^2,n,1,+infinity)=pi^2/3`。
   - 实际仍保留原积分。

另以独立的 40 位 mpmath 数值积分/数值微分核对所有参考答案；第 7 题使用振荡积分，
第 8 题用偶对称半轴积分。数值核对是补充证据，不代替符号证明。
