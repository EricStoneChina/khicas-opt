# KhiCAS 画图操作速查表

> 基于源码 zdisplay.cc 的按键映射整理(commit 80b7ec0)。
> 功能入口:计算器上运行 `plot(...)` 或从菜单进入画图后生效。

## 基础操作

| 按键 | 功能 |
|---|---|
| 方向键 ←→↑↓ | 移动光标(屏幕内) |
| SHIFT + 方向键 | 快速移动/大范围移动 |
| EXIT | 退出画图 |
| AC | 中断当前操作 |

## 功能键(F 键)

| 按键 | 功能 | 备注 |
|---|---|---|
| **F1** | 画图帮助(geohelp) | 随时可调出 |
| **F2** | 对象信息(光标处曲线/点信息) | 非 3D |
| **F3** | 切换"坐标跟踪"(trace mode bit 2) | 非 3D;开启后跟随曲线显示坐标 |
| **F4** | 切换"曲线点跟踪"(trace mode bit 4) | 非 3D |
| **F5** | 正交化视图(恢复等比缩放)+ 切换模式(bit 8) | 非 3D |
| **F7** | 反转跟踪方向 | |
| **XTT / Tab** | 曲线信息(curve_infos:表达式、定义域、参数) | 非 3D |

## 曲线信息界面(curve_infos)内

| 按键 | 功能 |
|---|---|
| EXE / OK | 确认 |
| EXIT | 返回 |
| ↑ / ↓ | 切换曲线 |
| ← / → | 调整参数(如区间) |
| DEL | 修改步长(step,输入新值) |
| CLIP | 裁剪视图 |

## 缩放与视图(zoomx/zoomy/zoomz)

源码实现三轴独立缩放与整体缩放(zoom 系列函数),实际按键在菜单/快捷入口中:
- 建议尝试:F1 帮助菜单里查看缩放快捷键说明
- 3D 模式:可单独缩放各轴

## 3D 模式附加工具键

| 按键 | 功能 |
|---|---|
| F8 | 清除当前绘制 |
| F9 | 画点(Point) |
| F10 | 画线段/圆(Center, Point) |
| F11 | 画三角形(Point1, Point2, Point3) |

## 追踪模式说明(tracemode 位)

| 位 | 含义 |
|---|---|
| bit 2 (值 4) | 坐标跟踪(F3):显示光标坐标 |
| bit 4 (值 16) | 曲线点跟踪(F4):光标吸附到曲线上 |
| bit 8 (值 256) | 正交视图(F5) |

## 与 CASIO 原版画图的对应

| CASIO 原版功能 | KhiCAS 对应 |
|---|---|
| 缩放框(V-Window) | F5 正交化 + 缩放系列 |
| 追踪(Trace) | F3/F4 跟踪模式 |
| 表格联动 | 无直接对应(建议用 spreadsheet) |
| 交点/极值(gsolve) | 在 CAS 命令行用 `solve`/`fmin` 等 |
