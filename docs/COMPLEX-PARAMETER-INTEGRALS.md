# 复参数积分与收敛条件

`checkpoint/complex-parameter-2026a` 将用户主验收集推进到35/36；剩余F5为Li2。D1–D4不再只验证正实参数：显式声明 `assume(a,complex)` 等后，输出带 `re(...)>0` 的条件公式，并在两种栈、直接积分/外层化简、冷加载/eager binding的32次调用中独立核对条件和答案。另有16次必要收敛边界检查和6个独立高精度复数积分参考。

对正实积分变量 (x)，复幂使用 (x^s=\exp(s\ln x)\)。

- 指数积分 \(\int_0^\infty e^{-ax}dx=1/a\) 的普通收敛域恰为 \(\Re a>0\)。非衰减纯振荡不返回有限 Abel 值。
- Gamma 定义积分在 \(\Re s>0\) 收敛。对正衰减实部的复尺度 \(c\)，\(\int_0^\infty x^{s-1}e^{-cx}dx=\Gamma(s)c^{-s}\)，\(c^{-s}\) 使用主值 Log；由正实尺度代换后在右半平面解析延拓，积分的局部一致支配保证同一公式成立。
- Beta 积分在 \(\Re a,\Re b>0\) 收敛。有限仿射区间先证明两个幂底数在区间内部为正，再计算线性换元的比例和区间长度，不拆分任意复数乘积的对数。
- Mellin 核满足 \(\int_0^\infty x^{s-1}/(1+x^q)dx=\pi/[q\sin(\pi s/q)]\)，条件是实 \(q>0\)、\(0<\Re s<q\)。端点渐近行为分别为 \(x^{s-1}\) 和 \(x^{s-q-1}\)，故不能把边界上解析延拓的有限值当作普通积分。

未知的条件保留为 `when`。D1、单位尺度Gamma、Beta、Mellin使用必要且充分的收敛条件，条件为假返回 `undef`。一般复尺度Gamma在纯虚轴上还可能条件收敛，所以不能把充分条件 `re(c)>0` 的补集统一标成发散：条件外以 `quote(integrate(...))` 保留待求值分支。若已能证明Gamma的原点收敛条件失败，则仍明确拒绝。

额外支持有严格正衰减实部的复数 Laplace 余弦/正弦核，以及最多4项、各项分别绝对收敛的复指数和。新题Q2的指数差走这一有界路径，避免通用积分和端点分析的小栈开销。

`_simplify` 保持未决 `when` 的惰性分支；已知条件会在正常求值阶段选择分支。这样不会为了化简条件表达式而提前求无定义的Gamma或对数分支。对于显式 `re(复变量)`，积分条件检查直接保留谓词，不进入无法证明的深层符号判断。原先主机64 KiB冷调用中的失败被复现，eager binding能区分加载器栈压力；新路径两种绑定方式均验证，未将此称为实机TLB复现。
