# 积分迭代 2 与 CG50 资源审计

基于 `checkpoint/integration-cycle1-2026a`（3f5fbde）。遵循先修复、验证、checkpoint，再委托生成新题的工作流。第二轮子代理独立生成 61 题，80 位参考校验全部通过；原始参考审计另存于 `docs/benchmarks/cycle2-reference-verification.txt`。

## 本轮逐项补齐

| 缺口 | 本轮算法与适用条件 |
| --- | --- |
| Mellin 对数权重，1 未解 + 1 原仅数值验证 | 对 x^(p-1)/(A+B*x^q) 的 Mellin 公式求参数导数，支持 0–2 阶 ln(x)；A、B>0，0<p<q，精确有理参数 |
| Beta 对数权重，3 未解 | 正区间 (0,1) 内提取 x 与 1-x 的实幂；用 Gamma/Psi 表达式处理总阶数不超过 2 的对数导数，参数 0<p,q<=16 |
| 带相位的阻尼 Laplace，3 未解 | 最多 8 项 sin/cos/常数线性组合，验证原点抵消与正指数衰减，保留相位 |
| 阻尼余弦差，2 未解 | 与上一项共用求解路径，不为每个频率组合单独硬编码 |
| 逆 Gaussian，2 未解 | x^(-1/2) 或 x^(-3/2) 乘 exp(-a*x-b/x+c)，a,b>0，正半轴 |

新增 21 个恒等式、20 个拒绝条件及零/一次幂规范化检查。拒绝路径包含不满足匹配条件的可积近邻，并不表示这些题数学上发散。

稀疏多项式识别改为引用原项序列，去除整个临时向量复制。公共规范化处理 x^0 与 f^1，避免等价输入漏匹配，同时保留引擎对字面量 0^0 的未定义语义。有限项变换优先避免中间表达式膨胀；未修改舍入精度、数值容差或时钟。

## 代码与内存

将 19 个有界积分辅助函数放入现有 AC2 代码区（含新增函数），保留主积分器在 ROM，未改变任何内存区地址和 CAS 堆大小。链接脚本包含真机和模拟器两种布局。`tools/check-resources.py` 检查实际二进制大小、链接容量及每个所选函数的落点。

| 区域 | 使用字节 | 上限字节 | 剩余字节 |
| --- | ---: | ---: | ---: |
| rom | 2,038,296 | 2,065,152 | 26,856 |
| ram | 424,620 | 442,368 | 17,748 |
| r8c2 | 2,314,300 | 2,559,996 | 245,696 |

CAS 堆配置仍为 1,572,864 字节。主 ROM 与 AC2 合计尚有 272,552 字节余量；不能声称已达到代码容量上限。静态 RAM 余量不能算入 CAS 堆。通过把代码放进既有 AC2 预留区，本轮主 ROM 使用量比上一 checkpoint 少 20,736 字节，两个代码区合计增加 7,480 字节。

## 真机测量入口

```xcas
time(integrate(x^5*(1-x^3)^50,x,0,1),"resources")
```

仅计算一次，返回：

```text
[结果, 秒数, 计算前堆空闲字节, 计算后堆空闲字节,
 本次启动以来堆已用字节峰值, 耗尽失败次数增量, 碎片化失败次数增量]
```

RTC 分辨率为 1/128 秒；短计算显示 0 秒并不表示零成本。第五项是分配器自启动以来的累计峰值，不是单题独占峰值，也不包括静态池和栈。前后快照不包括返回统计列表的额外分配。若要比较单题，应使用相同启动状态、时钟、精度和角度模式；重新启动应用后逐题测量，并记录基线。分配失败若中断表达式而无法返回统计，应单独记为失败，不记作求出。

安装包含 `CG50TEST.xw`；在 KhiCAS 中执行 `read("CG50TEST.xw")` 后，以 `cgtest(1)` 至 `cgtest(15)` 单独运行原始 8 题、原崩溃题、新算法代表题和两项规模测试。脚本本身会占用堆；测量结果应与同一脚本基线比较。脚本使用局部 x，不清除用户变量。

USB 存储连接只允许传输文件，不能代替按键执行、看到屏幕结果或测量运行峰值。安装成功和数学正确性不等同于已通过真机运行验收。
