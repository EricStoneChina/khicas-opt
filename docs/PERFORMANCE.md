# Checkpoint 1：KhiCAS 上游基线上的性能优化

基线：`upstream/khicas-2026-07-31`，来自作者当前正式 Casio 源码包，
日期与 SHA-256 记录在 `UPSTREAM.json`。此 checkpoint 没有新增方程转换命令。

## 源码修改

- `libbf.c`：大数与 64 位小整数的乘加使用调用者栈上的只读 limb 操作数，
  去掉每次临时操作数的堆分配与释放。运算与舍入仍调用原 `bf_mul` / `bf_add`。
  同时修正 `INT64_MIN` 有符号取负、32 位移位边界、零长度 `memcpy`。
- `zvecteur.cc`：转置直接读取源矩阵；不先复制外层矩阵，不分配迭代器数组。
  补齐输入输出别名与指定宽度的处理，避免截断输出时辅助数组越界。
- `tools/build.py`：对积分（`yintg/zintgab/zrisch`）、化简（`zlin/zseries/zusual`）、
  求解（`zsolve/zcsturm/zifactor`）、矩阵（`zvecteur/zgauss`）使用
  `-O2 -finline-functions`，其余保持 `-Os`；函数/数据分段交给链接器回收。
  原始根目录 `Makefile` 保持官方原样，路径和并行帮助生成修复仅应用到构建目录。

没有修改积分公式或数值积分的误差控制，没有 fast-math、LTO、堆扩容或时钟调整。
`-O2` 对目标设备的具体提速需要实测，不能由编译成功推算。

## 测试

- 32/64 位 limb 各 127,008 组结果和状态比对，共 254,016 组；
  覆盖舍入、精度、特殊值、整数边界、输出别名及分配失败。
  AddressSanitizer / UndefinedBehaviorSanitizer 通过，并检查所有跟踪的大数内存已释放。
- 连续 200,000 次小整数乘法，32 位测试的堆分配从 200,491 次降到 490 次；
  64 位从 600,000 次降到 400,000 次。该数据仅表示专项分配开销。
- 9,902 个实际转置函数用例，通过主机 Giac 检查。
- 10 个符号积分（检查不是未求出的积分，再求导核对）及 4 个数值积分，通过主机 Giac 检查。
- 基准脚本已在主机 Giac 中执行：`bench/bench.xws`、`bench/integration.xws`。
- 官方与优化版都完成 SH4 交叉编译、链接和 g3a/ac2 打包。

主机 CAS 测试使用 Giac 1.9 库；交叉编译使用本 worktree 中固定的官方源码。
没有计算器或模拟器运行数据，暂不报告整体计算、符号积分或数值积分的加速百分比。
