# 开发与出题流程

按用户最新要求：

1. 主代理负责分析错题、修复实现、性能与资源测量、参考答案校验、完整回归验收。
2. 验证通过后创建 checkpoint，更新独立的已通过题目 Markdown；安全保留原式不算求解成功。
3. 每次最多派发一个全新 subagent，仅根据错题家族出类似题、参数变体、结构变体及边界题，不承担修复或引擎验收。
4. 出题代理交付后结束其运行，主代理独立核验参考答案并冻结题集。下一次创建全新上下文，不复用旧代理。
5. 把新发现的失败逐项记录，再由主代理修复与验收。明确区分算法缺口、校验器缺口和实际资源限制。

此前参与实现的代理已停止，后续不再复用。工具目前可以停止代理运行，不能删除会话历史；停止运行与删除历史不是同一操作。
