### 2.2 中文帮助(阶段一)

**数据链路**
```
tools/help-zh.json  (cmd → {howto, ex1, ex2})
      ↓ tools/help-zh-gen.ps1
giacbf/static_helpzh.h   (纯 ASCII;中文=GB18030 字节 + 0x01 标记)
      ↓ 编译
khelpzh.o → has_static_help() → 帮助框
```

**渲染接入**
- `giacbf/khicas_gb18030.h/.cc`:自包含 syscall thunk(EnableGB18030 0x01E0 / DisableGB18030 0x01DF / ProcessPrintChars 0x1300,经 0x80020070 分发器),不依赖 libfxcg 版本
- `zdisplay.cc`:`os_draw_string` / `os_draw_string_small` / `text_print` 剥 `0x01` 标记 + 切换字符集
- `textGUI.cpp`:`print()` 同样处理;**display() 元素级标记**(整行生效)+ **CJK 逐字换行**(中文无空格,原按空格分词会溢出屏外)
- `graphicsProvider.cpp` `mPrintXY()` + `menuGUI.cpp` 标题:菜单文本的标记处理

**翻译覆盖**:102 条(每条含中文说明+用法+2 个完整示例),见 `tools/help-zh.json`

### 2.3 界面汉化(阶段二)

**机制**:运行时查表 + 开关,不改原有逻辑

- `giacbf/khicas_zhui.h/.cc`:`zhui(en, fr)` —— `zh_ui_enabled` 非零时查中文表,否则回退原 `lang?fr:en`
- `zh_ui_enabled` 定义在各 `catalogXX.cpp`:`catalogen.cpp=0`(英)、`catalogfr.cpp=0`(法)、`catalogzh.cpp=1`(中)
- `tools/ui-zh-gen.ps1` 自动把 **97 处** `lang?"fr":"en"` 改写成 `zhui("en","fr")`(表内没有的 22 处保持原样)
- **24 个目录分类名** + **86 条 UI 字符串**中文
- About:`Khicas 1.8.0 中文版` + `由 EricStoneChina 构建 (2026)`

### 2.4 目录帮助增强

目录命令按 F5 时,`catalogen.cpp` 用的是**内置英文 desc**、示例只是**参数值**(如 `isprime` 的示例是 `"11"`)。
`tools/make-catalogzh.ps1` 会改写 `catalogzh.cpp`:

- `desc` → 中文说明+用法
- `example`/`example2` → `#完整示例`(`#` 是 `catalogen.cpp` 里的**原样显示/插入通道**,否则会被拼成 `命令名+参数+")"`)
- 共改写 49 条目录条目 + 24 个分类名

## 4. ⚠️ 关键坑(务必遵守)

| # | 坑 | 说明 |
|---|---|---|
| 1 | **新增源文件不要以 `z` 开头** | `prizm.ld` 用 `z*.o` 通配符把 z 开头的目标文件收进 `.rominram`(第二段,上限 2,559,996B)。基线 `.ac2` 已 2,557,376B,**只剩 2620 字节余量**。本会话 `zhui.o` 就因此溢出 1100 字节 |
| 2 | **第二段文件名硬编码** | `main.cc` `chk_ram2M()` 只把 `ram_filename` 的 `.8c2` 换成 `.ac2`/`.882`;`ram_filename` 定义在各 `catalogXX.cpp`。中文版必须链 `catalogzh.o`(→ 加载 `khicaszh.ac2`),否则会加载机器上旧版的 `khicas50.ac2` → **Illegal Code Err PC=00000000** |
| 3 | **g3a/ac2 必须成对** | 版本不匹配会崩溃;安装前删掉根目录所有旧 `khicas*` |
| 4 | **GB18030 标记协议** | 中文串必须以 `0x01` 开头;渲染层剥标记 + `EnableGB18030()`;textGUI 是**元素级**(整行)生效 |
| 5 | **`\x01` 转义** | 后接十六进制字符会被吞(`\x01DEL` → `\x01D`),生成器必须在 `\x01` 后加 `""` 分段 |
| 6 | **PS 5.1 脚本编码** | `.ps1` 按 ANSI 读 → 脚本正文保持纯 ASCII,中文放独立 UTF-8 数据文件 |
| 7 | **母本编码** | `static_help.h` 是 UTF-8;字节级解析用 Latin-1 读,**写回也必须 Latin-1**(否则二次编码) |
| 8 | **目录帮助数据源** | 目录命令的 F5 帮助用 `completeCat[].desc`,**不走** `static_help` |
| 9 | **字段顺序** | `static_help.h` 里是 `name,{howto×5},syntax,EXAMPLES,RELATED`,与 `khelpfr.cc` 结构体命名相反(所以 `fexamples` 是对的) |
| 10 | **诊断口诀** | 启动提示 `Fatal: unable to load ram part` = ac2 缺失/名字不对;`Illegal Code Err PC=0` = ac2 找到但版本不匹配 |
