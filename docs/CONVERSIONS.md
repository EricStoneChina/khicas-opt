# 方程转换

优化版新增六个内置命令，英文、法文构建均可使用。在命令目录的绘图或求解分类中可以找到，带输入示例。

这里的“普通方程”指直角坐标方程，包括 `y=f(x)`、`x=f(y)` 和隐式方程 `F(x,y)=0`。裸表达式 `F` 按 `F=0` 处理。

| 方向 | 调用 | 返回 |
|---|---|---|
| 普通 → 参数 | `cart2param(eq,[x,y],t)` | 所有可求出的分支 `[[X(t),Y(t)],…]` |
| 参数 → 普通 | `param2cart([X,Y],t,[x,y])` | 消元后的隐式方程；常值点返回两个同时成立的方程 |
| 普通 → 极坐标 | `cart2polar(eq,[x,y],[r,theta])` | 关于 `r,theta` 的隐式方程 |
| 极坐标 → 普通 | `polar2cart(eq,[r,theta],[x,y])` | 标准极坐标域下的隐式方程 |
| 极坐标 → 参数 | `polar2param(eq,[r,theta],t)` | 直角坐标参数分支 `[[X(t),Y(t)],…]` |
| 参数 → 极坐标 | `param2polar([X,Y],t,[r,theta])` | 消元后的极坐标方程 |

`param2polar([X,Y],t)` 的两参数形式返回 `[r(t),theta(t)]`，适合不需要消元或无法消元的曲线。

数学窗口会把直接转换结果排版为 `[x(t)=…, y(t)=…]`；底层仍保留上述列表接口。
自定义名称、复制保存行为和显示范围见 [PARAMETRIC-DISPLAY.md](PARAMETRIC-DISPLAY.md)。
本轮验证与空间报告见 [EQUATIONS-2026a.md](EQUATIONS-2026a.md)。

## 输入约定

- 使用弧度模式。涉及三角函数的转换在角度模式下会提示切换，不自动修改全局设置。
- 坐标、参数名称必须未赋值且互不相同。必要时先 `purge(x,y,t,r,theta)`。支持自定义名称，例如 `cart2param(v=u^2,[u,v],s)`。
- 参数坐标用表达式对 `[t,t^2]`，不要输入 `[x=t,y=t^2]`。
- 普通方程和极坐标方程允许隐式结果，不强制把结果解成单一函数，以免丢掉分支。

## 示例

```xcas
cart2param(y=x^2,[x,y],t)
// [[t,t^2]]

cart2param(x=3,[x,y],t)
// [[3,t]]

cart2param(x^2+y^2=4,[x,y],t)
// [[t,sqrt(4-t^2)],[t,-sqrt(4-t^2)]]，分支顺序可能不同
// 实曲线要求 -2 <= t <= 2

cart2param(x*y=0,[x,y],t)
// [[t,0],[0,t]]，保留两条直线

param2cart([cos(t),sin(t)],t,[x,y])
// x^2+y^2-1=0

cart2polar(x^2+y^2=4,[x,y],[r,theta])
// r^2-4=0，标准极坐标取 r>=0

polar2cart(r=2,[r,theta],[x,y])
// sqrt(x^2+y^2)-2=0

polar2param(r=1+cos(theta),[r,theta],t)
// [[(1+cos(t))*cos(t),(1+cos(t))*sin(t)]]

param2polar([cos(t),sin(t)],t,[r,theta])
// r^2-1=0

param2polar([3,4],t)
// [5,atan(4/3)]
```

得到参数分支后，可以取某个分支绘图：

```xcas
branches:=cart2param(x^2+y^2=4,[x,y],t);
plotparam(branches[0],t=-2..2);
plotparam(branches[1],t=-2..2);
```

## 等式化简与标准曲线

`simplify` 现在会约去多项式等式的非零有理数公共因子：

```xcas
simplify(-27*x^3+81*x*y-27*y^3=0)
// x^3-3*x*y+y^3=0

simplify(x/2+y/3=0)
// 3*x+2*y=0

simplify(2*x*y=0)
// x*y=0，保留 x=0 和 y=0
```

参数转普通方程的结果也会自动去掉这种多余因子。不会把 `x*y=0`
除以变量 `x`，也不会为了约分清除含变量的分母。已有的显式 `x=2`
不会强制改写为移项后的等式。

笛卡尔叶形线优先返回有理参数式：

```xcas
cart2param(x^3+y^3=3*x*y,[x,y],t)
// [[3*t/(1+t^3),3*t^2/(1+t^3)]]，t != -1

cart2param(-27*x^3+81*x*y-27*y^3=0,[x,y],t)
// 相同参数式
```

已知正参数也可以保留，例如先 `assume(a>0)` 后转换
`x^3+y^3=3*a*x*y`。系数为零时曲线退化为直线，直接返回 `[[t,-t]]`。
不会把这种退化情况误当作单独一个原点。

伯努利双纽线使用紧凑的三角参数式，`0<=t<=2*pi` 覆盖两瓣：

```xcas
cart2param((x^2+y^2)^2=x^2-y^2,[x,y],t)
// [[cos(t)/(1+sin(t)^2),sin(t)*cos(t)/(1+sin(t)^2)]]
```

若右侧乘正系数 `K`，两个坐标乘 `sqrt(K)`。负系数对应交换两个坐标；
零系数返回原点。分母 `1+sin(t)^2` 对实参数始终为正。

普通转参数也会先检查哪个坐标能直接解出，例如 `x+y^5+y=0`
现在返回 `[[-t^5-t,t]]`，无需先求一个五次方程。
符合有理直线束条件的其他曲线会保留缺失的竖直分支或孤立点。

极坐标的奇次幂半径使用实根：例如 `r^3=sin(theta)` 在正弦为负时
仍返回实数参数坐标，使用 `sign(g)*abs(g)^(1/3)` 表示实立方根。
不会把负数的主值复立方根当作实平面曲线坐标。

## 紧凑的双纽线与笛卡尔叶形线

`cart2polar` 对以下曲线返回课本常用形式（`K` 是原方程中的系数）：

```xcas
cart2polar((x^2+y^2)^2=K*(x^2-y^2),[x,y],[r,theta])
// r^2=K*cos(2*theta)

cart2polar(x^3+y^3=6*x*y,[x,y],[r,theta])
// r=6*sin(theta)*cos(theta)/(cos(theta)^3+sin(theta)^3)
```

这些形式与原式描述**同一条直角坐标曲线**，并保留原点。它们约去了代入式中的
`r^2`；因此不再为原点保留所有重复的角度标签。双纽线的原点可取
`theta=pi/4`，叶形线的原点可取 `theta=0`。转换时会显示这一范围说明。

双纽线仍保留 `r^2`，没有选择或丢弃负半径分支；取实半径时需满足
`K*cos(2*theta)>=0`。`K=0` 返回原点曲线 `r^2=0`。

叶形线的显式半径要求 `cos(theta)^3+sin(theta)^3!=0`，也就是排除
`theta=3*pi/4+n*pi`。当 `K` 已知非零，这些角度上原曲线只有原点，且原点已由
其他角度表示；没有丢失非原点。若采用标准极坐标，再取 `r>=0`；有符号半径
可通过 `polar2param` 使用。

当 `K` 未知是否为零或确实为零，叶形线保留紧凑隐式形式
`r*(cos(theta)^3+sin(theta)^3)=K*sin(theta)*cos(theta)`，不除以角度分母。
这会保留 `K=0` 时的整条直线 `x+y=0`。也不会约去未证实非零的整体参数因子，
以免把参数退化时的整个平面误转成某条曲线。其他曲线仍走原有的直接代换路径。

## 范围与数学限制

**参数范围和原表达式的定义域需要保留。** 返回的方程或表达式不携带区间条件、分母非零条件、根号实数条件，也不包含外部假设的完整副本。含附加参数的方程还需要单独检查使系数为零的特殊取值。分支数量不等于曲线连通分量数量。

`param2cart` 对显式图像直接代入，其他有理参数曲线使用结式消元；标准 `sin(t),cos(t)` 通过半角代换转为有理形式。结式返回的是**代数闭包**，不是带参数范围的精确点集。例如 `[t^2,t^3]` 给出 `y^2=x^3`；`[t^2,0]` 给出直线方程，但实参数仍要求 `x>=0`。有理参数的分母零点、半角代换的缺点也需单独检查。消元路径会显示英文提示。不能可靠消元的组合，如 `[sin(t),exp(t)]`，明确报错；可保留参数形式或使用两参数版本的 `param2polar`。

`polar2cart` 使用 `r=sqrt(x^2+y^2)` 与 `theta=arg(x+i*y)`，适用范围是 **`r>=0`、主值角**；方向角在原点没有定义，需回到原方程单独判断原点。没有把等式两边平方，因此不会为了去掉根号而引入额外分支。非周期的角度表达式也受主值角范围约束。

若原方程使用负半径或多圈角度，例如 `r=-2`，请先 `polar2param` 保留角度参数，再按需要用 `param2cart` 消元，并保留原参数范围。`polar2param` 支持有符号半径；对射线 `theta=pi/4` 返回 `[t/sqrt(2),t/sqrt(2)]` 时，标准半径约定需另取 `t>=0`。

不存在能够为任意隐式曲线自动给出全局单一参数式的通用转换。本实现复用 Giac 的符号求解能力，保留求出的分支；求解未完成、变量冲突或不支持的消元会报错。

- 六向转换共 36 个成功与错误处理用例，通过主机 Giac 1.9 回归检查；转换基准脚本也已执行。
- 继续通过 9,902 个转置用例、10 个符号积分与 4 个数值积分检查。
- 静态命令表在 RELEASE 开关的两种配置下分别检查 906 / 900 个命令，
  确认名称有序、无重复，全部上游命令的函数映射与属性保持一致。
- 英文 FX-CG50 版完成 SH4 交叉编译、链接及 g3a/ac2 打包。
  最终主段 ROM 为 2,029,816 字节，第二段为 2,286,436 字节，静态 RAM 为 424,604 字节。
  相比性能 checkpoint，转换功能新增主段 9,012 字节，第二段和静态 RAM 不变。

主机测试不等于计算器运行验证；尚未实测真机速度或交互。
