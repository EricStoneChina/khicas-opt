## 通用算法和条件

这些路径识别表达式结构及数学条件，不按题号或完整输入查答案。

- **Gaussian 对称性**：`exp(-a*x^2)/(1+exp(k*x))`，`a>0`、实系数、全实轴。
  两个反射项相加为 Gaussian，故积分为 Gaussian 全轴积分的一半。
- **同号留数有理核**：`R=sum(a_i/(x-b_i))`，实极点、所有非零留数同号。
  对正留数，`R` 在相邻极点间严格递减。`R(x)=t` 的根之和为
  `sum(b_i)+sum(a_i)/t`，因此逆分支的总绝对 Jacobian 为 `sum(a_i)/t^2`。
  将 `R^2/(1+R^2)` 在所有分支上换元，得到 `pi*sum(a_i)`；全负留数取绝对值。
  拒绝混合符号、非实极点、非零多项式部分。可去的孤立缺点不改变积分。
- **实奇次根换元**：`t=surd(a*x+b,n)`，非零有理数 `a`、有理数 `b`、奇数 `3<=n<=9`。
  同时处理源码的 `surd` / `NTHROOT` 表示及负根指数的倒数，换成
  `x=(t^n-b)/a`、`dx=n*t^(n-1)/a dt`。只有新积分全部求出才接受；返回规范实根表示。
  不替换复数主值幂，不处理偶次根或不同被开方表达式。检查临时变量冲突。
- **倒数 Gaussian**：`exp(-a/x^2)/x^2`、`a>0`、正半轴，通过 `u=1/x` 化为半轴 Gaussian。
- **正端点发散**：`exp(q*x^2)/x^2` 在正半轴的零端点、`1/(x^2*ln(x))` 在从 1 向右的区间。
  正函数的局部不可积极点足以判发散；不将跨越奇点的积分误当作主值。
- **正切反射**：`1/(1+tan(u)^p)`，实常数 `p`、仿射 `u`，端点恰好对应 `0` 与 `pi/2`。
  内部正切为正，反射把它变为倒数，两个被积函数之和为 1。只用于弧度模式。
- **对数反射**：`ln(K*(1+u))/(1+u^2)`，`K>0`、仿射 `u`，端点对应 0 和 1。
  `u -> (1-u)/(1+u)` 保持积分权重并使两个对数之和为常数。检查正实对数的定义域。

上述定积分路径支持外部有理常数因子及反向积分区间。结构扫描限 128 个节点，
有理核限 8 项；根换元另限制显式幂次数，避免试探换元展开极高次多项式。
仅规范化算术结构，避免提前展开指数函数而失去换元线索。
未匹配的表达式继续交给原算法；原来的递归保护和未求出积分表示仍保留。

python3 tests/run-real-definite.py

直接规则测试包括 25 个定积分变式、24 个拒绝条件、32 个跨正负实轴的根式导数采样、
6 个不适用根式情形。整库测试直接编译本仓库积分/定积分及归一化模块，其他依赖为
主机 Giac；不是把全部计算委托给主机库。每题限 10 秒、768 MiB 虚拟地址空间。
主机计时不含进程启动和答案验证，不能换算为 CG50 耗时。
本次这 8 题各为约 0.30–0.51 ms（单次测量，包含输入解析）。

原用户立方根幂算例在 64 KiB 栈限制下仍正常完成，结果与旧实现一致；旧实现仍失败。
该测试修复的是已复现的栈压力问题，不能据此保证所有真机 TLB error 都已消除。

## 目标构建与回退

仅对新增的结构判断/换元函数使用 GCC `Os` 和禁止内联，减少 ROM 占用；
原有计算热点继续按原构建策略优化。本轮由此再省 **3,184 字节**主 ROM。

| 区域 | 上一 checkpoint | 本轮最终 | 变化（字节） |
|---|---:|---:|---:|
| 主 ROM | 2,035,368 | 2,043,080 | +7,712 |
| 静态 RAM | 424,620 | 424,620 | 0 |
| 第二段 AC2 | 2,286,152 | 2,286,152 | 0 |

主 ROM 余量 **22,072 字节**。这是增加算法后的总体积代价，不能宣称程序整体缩小。
SH4 栈报告中，新结构规范化函数单帧 96 字节、定积分分派 308 字节、实根换元 268 字节；
这些是单帧静态值，不代表整次积分的最大栈或动态内存峰值。

两个阶段的配套安装包分别保存在 `dist/cg50-2026a-checkpoint` 和
`dist/cg50-2026a-integration`，包含提交号和 SHA-256。旧安装包及设备备份保留。
最终构建不等于已安装：本轮结束时未检测到 CG50 存储设备，未写入计算器。
