# 用户 A1–F6 验收集：参考答案与条件

题目来自用户自行整理的表格。Markdown 中被竖线拆开的绝对值已还原为：A1 为 `x*abs(x)/2`，A2 为 `abs(x)`，A3 为 `ln(abs(ln(x)))`，A6 为 `ln(abs((x-1)/(x+1)))/2`，D5 指数为 `-a*abs(b)`；D6/E2 要求 `a>|b|`，E1/E4/E5/E6 要求实参数 `|r|<1`。这 36 个参考答案在所列条件下成立。以下是主代理的独立核对依据，不能替代对实际输出的验收。

## A：实分支

在 x 的正负半轴分别使用 `sqrt(x²)=abs(x)`。A1 的原函数在零点可导，导数为零；A2 的原题排除零点。A3 令 u=ln(x)，两个开区间上的原函数是 ln|u|。A4 在 1/2 拆分，两个三角形面积为 9/8 与 25/8，总计17/4。A5 在 π 处分段，总面积4。A6 的部分分式为 `(1/(x-1)-1/(x+1))/2`，在三个开区间分别使用实对数。

## B：反射与 Catalan

B1 用 x→π/2−x，两个分子相加恰为分母；分母在闭区间严格正，因此两个积分的和为π/2。B2 同理用 x→1−x，分母严格正，结果1/2。B3 的无权核关于π/4对称，所以权重x可换为π/4；`sin x+cos x=sqrt(2) cos(x−π/4)`，积分结果为所列表达式。

B4 的 atan 幂级数积分和为 `Σ(-1)^k/(2k+1)^2=G`；B5 对 `1/(1+x²)` 的级数积分得到其相反数。B6 由 `ln(2cos x)` 的 Fourier 级数在0到π/4积分得到 `−π ln2/4+G/2`。测试文件用 `(Psi(1/4,1)-Psi(3/4,1))/16` 表示G，避免把未绑定的字母G当作常数。

## C：普通积分而非主值

C1 两个指数项必须先合并：在零点差值为O(x)，在无穷指数衰减。对b求导得到1/b，并用a=b时积分为零定常数。C2 对b求导是 `a/(a²+b²)`，由b=0得atan(b/a)。C3 对b求导是 `b/(a²+b²)`，由b=0得半个对数。C4 为通常的 Dirichlet 积分，收敛但不绝对收敛。

C5 的截断积分为sin(T)，极限不存在。C6 的正半轴截断积分为 `ln(1+T²)/2`，发散；负半轴单独也发散。对称相消仅给出PV=0，不能作为普通积分结果。

## D：参数域属于答案的一部分

D1 在 Re(a)>0 时积分指数原函数，两端极限给1/a。D2与D3分别是Gamma与Beta积分定义，端点指数必须满足所给实部条件。D4 是 `Beta(s,1−s)`，用Gamma反射恒等式得到 `π/sin(πs)`；收敛带严格为0<Re(s)<1。

D5 可对整条实轴使用留数法：b>0闭合上半平面，b<0闭合下半平面，因此指数必须包含abs(b)；偶性再取一半，b=0由连续性得到同式。D6 以半角换元或Poisson核求整周期，`a>|b|` 固定了正根并排除了实极点。

目前主机旧假设接口不能直接处理 `assume(re(a)>0)`；仅测试 `assume(a>0)` 是正实数子域，不能声称验证了完整复半平面。D2/D3/D4同样保留这一差别。未提供假设时的输出另记，不把自动省略收敛条件当作成功。

## E：统一 Fourier 核

实|r|<1时：

```
1/(1−2r cos x+r²) = (1+2 Σ[k>=1] r^k cos(kx))/(1−r²)
ln(1−2r cos x+r²) = −2 Σ[k>=1] r^k cos(kx)/k
```

级数在固定|r|<1时可逐项积分，常数项与余弦正交性分别给E1、E4、E5、E6。E5的n=0必须保留，E6只适用于n>=1。

E2令 `q=b/(a+sqrt(a²−b²))`，将对数参数提取正因子 `(a+sqrt(a²−b²))/2` 后化为上述核，余弦项平均为零。E3取 `q=sqrt(3)−2`，展开 `1/(2+cos x)`，其第3个Fourier系数给所列负值。

符号整数n的通式要求引擎真的支持整数假设；替换几个数值n不能代替这一要求。

## F：特殊函数规范

对参考原函数按定义求导即可。F2采用 `S(z)=∫[0,z] sin(πt²/2)dt`，因此系数与变量缩放相乘正好给导数sin(x²)。引擎若输出复erf的等价组合，可以通过严格导数恒等检查，不必伪称已经注册了名为FresnelS的计算器函数。F5使用 `d Li₂(x)/dx=−ln(1−x)/x`；F6由链式法则得到 `d Ei(ln x)/dx=1/ln x`，实区间不跨x=1。
