# 积分迭代 1：收敛变换与资源账本

基于 `checkpoint/generalized-integrals-2026a`（3b429f9）。独立 152 题中的 10 个未求出项现均通过精确验证。

| 缺口 | 新增覆盖 |
| --- | --- |
| 阻尼 Dirichlet，2 题 | 正衰减指数乘 sin(bx)/x 的半轴积分，允许有理频率及指数常数 |
| Logistic 十阶矩，1 题 | 偶矩 Bernoulli 公式；整数阶支持至 16 |
| Logistic 平移，2 题 | 二项式展开中心矩，最多 9 项，支持奇数阶和平移 |
| 加权三角反射，1 题 | 正定分母 A+B*cos²(u) 的 B<0 情形，用 atanh |
| Gaussian Fourier，1 题 | 实有理二次指数配方及仿射 sin/cos，相位保留 |
| 对数三角，2 题 | 正半波、四分之一波，以及绝对值的整周期 |
| Fermi 矩，1 题 | x^n/(exp(ax)±1)，阶数 0–16，正 a；保留 Zeta 精确表达式 |

明确检查实数条件、收敛方向、区间及奇点；不把普通发散积分改成主值。另增 24 个恒等式和 18 个拒绝条件检查。修复平移为零时引擎将 0^0 视为未定义的问题。

## 验证

- 独立泛化 152 题：150 精确、2 采样验证；无未求出、未定义、超时或错误。
- MIT / Princeton 168 题：160 精确、7 采样、1 数值常数验证；与上个 checkpoint 状态一致。
- 用户原始 8 题：全部精确，全部在主机 64 KiB 栈限制下返回相同结果。
- 定积分单元测试：旧测试全部通过，新增 24 恒等式及 18 拒绝条件通过。
- SH4 目标构建成功。数据记录于 `docs/benchmarks/*cycle1-2026a.json`。

主机测试编译仓库积分和归一化模块，其余依赖来自主机 Giac；计时、RSS 和栈限制不代表 CG50 实测。采样和数值验证不等同于全域符号证明。

## CG50 实际构建容量

| 区域 | 使用字节 | 配置上限 | 余量 |
| --- | ---: | ---: | ---: |
| 主程序 ROM | 2,059,032 | 2,065,152 | 6,120 |
| 静态 RAM | 424,620 | 442,368 | 17,748 |
| AC2 代码 RAM | 2,286,084 | 2,559,996 | 273,912 |

相比上轮，主程序增加 5,040 字节；其余两区不变。新增变换函数 SH4 单帧静态栈为 180–300 字节，这不包括被调用函数和递归的总栈。

`main.cc` 将 CAS 堆配置为 1,572,864 字节；240 KiB 的静态分配区另用于 MicroPython。静态 RAM 余量不是 CAS 可用堆。主 ROM 已近满，但 AC2 仍有空间，因此不能据此声称整机已到容量上限。

下一轮须在本 checkpoint 后生成新独立题集。真实运行内存峰值、耗时及 TLB 回归仍需连接 CG50 测试；目前未检测到该设备。算法未覆盖、验证不足和硬件资源超限必须分别记录。
