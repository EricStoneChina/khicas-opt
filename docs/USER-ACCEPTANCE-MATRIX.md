## 已验证的扩展

新增33道结构变体全部通过132次精确检查；另以65位精度独立计算25个定积分的数值参考。覆盖负比例、反向区间、不同尺度／幂次、多项相消、负频率、符号参数和整数Fourier阶数。四次根式通过代数微分恒等式及多个实区间检查。

绝对值仿射函数直接算端点，三角绝对值直接算整周期，避免逐个搜索零点。正值三角对数及Poisson核用均值和Fourier系数计算。振荡Frullani先证明相消及指数衰减，避免分别计算发散项。

`simplify` 对含多变量根式的单个对数乘积保留对数为原子，仍进行外部有理化简，避免建立不必要的代数扩张及展开对数。旧主机64 KiB冷调用能复现崩溃，开启eager binding后旧版可通过；新版默认冷调用和eager binding均验证。此处不把主机加载器栈压力称为实机TLB已复现。
