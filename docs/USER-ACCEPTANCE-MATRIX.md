## 三项错误答案修复

- B1：旧版错误返回无穷；通过正分母与反射配对证明，返回π/4。该规则同时让B2直接返回1/2并避免通用高次求解路径。
- C6：旧版将奇函数的PV=0当作普通积分。新的有界有理渐近分析识别非零1/x尾项，明确拒绝发散。通用奇函数零值路径必须先证明无实极点、存在次数不高于−2的有理包络；保留已证绝对收敛的奇函数结果。
- D5：旧版返回exp(−a*b)，b<0时错误增长；正二次核的Fourier通式显式保留abs(b)，正、负及零频率均有测试。

## 资源、回归与缺口

原有518条正式记录保持513条精确、5条导数采样；新验收集全模式通过的13条正结果另加入独立通过列表，重复题按来源保留。C6的拒绝行为不计入积分求解数量。9个反射变体、8个Fourier变体（含符号频率）、5个发散拒绝、13个不支持/预算边界在正常与64 KiB栈直接规则测试中通过；这些也不冒充新的正式题目数。

目标ROM 2056380/2065152 B，静态RAM 424620/442368 B，AC2 2428000/2559996 B；分别剩余8772、17748、131996 B，CAS堆不变。已完成实际SH4编译，但本 checkpoint 未再次写入计算器。

默认64 KiB下仍有20道直接积分执行失败。旧版24道失败的eager-binding诊断中，一部分是主机动态链接栈压力，另有A4/A5/B1/B3/C5/C6/D5/E1/E2/E3/E6在该诊断下仍失败；本轮已修其中B1/C6/D5的主路径。不能将全部主机失败统一归因于加载器，也不能把它们全部当作实机TLB复现。

下一步仍优先处理A4/A5的绝对值区间、B3–B6/C2–C3及E类核、D类完整符号收敛条件、F5的dilog能力，以及simplify剩余定义域与资源路径。用户此前5题已重新运行，20次组合均未精确通过，[实际记录](benchmarks/user-reported-five-gaps-matrix-2026a.json)保留失败状态，未计入通过题目。之后才处理圆/椭圆/双曲线分支及参数标签，[排期](NEXT-PRIORITIES.md)已记录。
