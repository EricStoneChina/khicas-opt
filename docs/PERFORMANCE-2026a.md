# 2026a：积分栈占用与计算热点优化

本文记录 `e2409f2` 阶段。后续剩余 8 题的完成情况见 [积分覆盖报告](INTEGRATION-COVERAGE-2026a.md)。

基线为 `checkpoint/equations`（`8b8fde1`）。原有性能、方程转换两个 checkpoint 保留。
此轮启动界面与 About 统一显示 `KhiCAS 2026a / 1.8.0`；`version()` 同步为 1.8.0。
2026a 是本地优化版标记，不是上游新发布版本。

## 用户算例与定位证据

```xcas
simplify(integrate((3*sin(x)-sin(3*x))^(1/3),x))
```

积分、换元、数值积分及 ODE 中，原代码以 `gen("tmpu",contextptr)` 等方式
创建内部变量，每次都会进入完整公式解析器。现在用 `identificateur` 直接构造同名符号，
不改变用户输入解析、积分精度或幂运算的分支规则。

SH4 GCC 7.3.0 的栈报告显示 `giac_yyparse` 单次静态栈帧为 **10,328 字节**。
把本仓库原始积分模块及归一化函数链接到主机 Giac 后，上述算例在 64 KiB 栈限制下
发生段错误；备用信号栈回溯定位到换元函数 `is_rewritable_as_f_of` 创建临时变量时的
`giac_yyparse`。改动后同一限制下计算完成，结果与旧实现一致。
这复现并消除了一个栈压力来源，尚未证明所有真机 TLB error 都由同一原因引起。

同一主机、同一构建方式、7 次独立运行：

| 专项 | 修改前 | 修改后 |
|---|---:|---:|
| 此算例解析器调用次数（含输入） | 9 | 1 |
| 此算例主机耗时中位数 | 24.80 ms | 25.63 ms |
| 64 KiB 栈限制 | SIGSEGV | 正常完成 |
| 10 万次接近满载的小对象分配，检查的位图项 | 6,400,000 | 100,000 |

此算例最新主机中位数约增加 3.3%；主要收益是减少解析器调用和栈压力，不能宣称普遍提速。
主机数据不能推算 CG50 或全部计算的提速比例。
位图检查次数也不是整体分配速度倍数。

## 其他改动

- 16/24/48 字节小对象池保存最早可用的位图位置；释放时更新位置。
  保留原先从低地址分配、池满后转入堆的行为，用 12 字节游标减少反复扫描。
- 指数与三角展开的二分幂算法交换工作缓冲区，去掉中间向量的复制。
- `ratnormal` / `recursive_ratnormal` 对已拥有的变量表直接排序，减少临时向量分配与复制。
- 积分只读参数与排版参数改为常量引用。
- 计算器上的积分启发式搜索检测相同子问题的递归环，并限制为 24 层嵌套；
  超限时保留未求出的积分部分。该限制不限制一层中相加的项数，也不保证所有其他
  算法都不会耗尽资源。递归入口检查 AC 中断请求。
- 对公共幂化简的返回类型先检查再读取向量，对空消元变量表先检查再调用 `back()`。
- 优化构建输出 `.su` 栈报告，便于后续定位大栈帧。

没有扩大堆、改变时钟、启用 fast-math 或改变误差容限。

## 验证与复现

```bash
ASAN_OPTIONS=detect_leaks=0 python3 tests/run-pool.py
python3 tests/run-symbolic.py
python3 tests/run-integration.py --stack-kb 64
python3 tests/run-cas.py
python3 tests/check-registration.py
TOOLS_DIR=/tmp/khicas-toolchain python3 tools/build.py optimized
```

主机数学测试需要 `libgiac-dev`。可通过 `GIAC_INCLUDE`、`CXXFLAGS`、`LDFLAGS`
指定依赖；`GIAC_NUMERIC_LIBS` 默认 `-lgmp -lmpfr`。积分比较器直接编译新旧 `yintg.cc`
及归一化函数，其余依赖使用主机 Giac 1.9。主机库缺少的新版向量场积分入口明确报错，
测试不以空实现伪造该功能；这些测试涵盖标量积分。

- 小对象池：32 位槽位、随机释放重用、池耗尽、分配失败和可选 32 字节池，ASan/UBSan 通过。
- 156 个指数/三角卷积幂结果与旧实现一致，递归保护的环检测、深度限制和退出恢复通过。
- 16 个实际积分模块算例与旧实现一致，包括用户原式、省略积分变量、实数立方根、
  变频三角函数、对数、有理式、Gaussian、符号和数值定积分。
- 既有 9,902 个转置用例、10 个符号与 4 个数值积分、36 个方程转换用例继续通过。

`^(1/3)` 与 `surd(...,3)` 的复数主值/实数根规则不是同一件事；这次没有将前者
强制改成后者。若题目明确要求实数立方根，可用 `surd(3*sin(x)-sin(3*x),3)`。

## 历年题库与有界算法

从 [MIT 官方档案](https://math.mit.edu/~yyao1/integrationbee.html) 选取 2010–2020、
2022–2026 共 16 年的 96 题，并加入 [Princeton MAT104](https://web.math.princeton.edu/~nelson/104/)
普通积分练习全部 49 题、反常积分练习 23 题，总计 168 题。不是全部历年赛题。
每题来源、输入、参考答案与验证点保存在 `tests/calculus-corpus.json`。

新增有界识别路径：高次多项式链式积分（避免展开）、稀疏多项式的反正切导数、
整周期高次偶数幂/绝对值三角函数、有限区间连续奇函数、仿射绝对值分段积分。
计算器静默模式省略可选数值日志预览，保留数值回退及精度设置。

每题独立进程，10 秒上限、768 MiB 虚拟地址空间上限；实际编译本仓库积分、定积分及
归一化模块，其余依赖主机 Giac。耗时不含启动和答案验证。详见
[机器可读报告](benchmarks/calculus-2026a.json)。
