Command Help

先看命令，再开始计算。

搜索 2026a 重点命令，查看中英文说明和可复制示例。

Li2(z)calculus

二重对数 / Dilogarithm

主值分支上的二重对数函数，支持实数和复数参数。

cart2paramconversion

笛卡尔 → 参数

将笛卡尔方程转换为参数分支，并保留实参数定义域。

cart2polarconversion

笛卡尔 → 极坐标

将笛卡尔方程转换为弧度制极坐标方程。

param2cartconversion

参数 → 笛卡尔

消去参数并返回笛卡尔方程，同时保留定义域排除项。

param2polarconversion

参数 → 极坐标

将参数曲线转换为极坐标；省略坐标列表时返回极坐标对。

polar2cartconversion

极坐标 → 笛卡尔

使用 r≥0 和主值角度转换，原点需要单独检查。

polar2paramconversion

极坐标 → 参数

把极坐标方程转换为弧度制笛卡尔参数分支。

Install once

两个文件，必须成对。

从同一次 Actions 构建中下载对应语言的 G3A 和 AC2，然后复制到 fx-CG50 存储根目录。

打开最新 Actions ↗
  1. 下载选择 khicas-en-baseline 或 khicas-zh artifact。
  2. 配对EN 使用 khicas50.g3a + khicas50.ac2；ZH 使用 khicaszh.g3a + khicaszh.ac2。
  3. 复制把同一包的两个文件复制到计算器存储根目录，覆盖旧版本前先备份。
  4. 启动从主菜单运行对应语言版本；如果出现加载错误，先检查两个文件是否来自同一次构建。
