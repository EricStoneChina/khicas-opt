03 / Command Help

从一个命令开始。

Li2(z)微积分

二重对数

计算主值分支上的二重对数函数，支持实数和复数参数。

cart2param坐标转换

笛卡尔 → 参数

把笛卡尔方程转换为参数分支，并保留实参数定义域。

cart2polar坐标转换

笛卡尔 → 极坐标

把笛卡尔方程转换为弧度制极坐标方程。

param2cart坐标转换

参数 → 笛卡尔

消去参数并返回笛卡尔方程，同时保留定义域排除项。

polar2cart坐标转换

极坐标 → 笛卡尔

按 r≥0 约定转换极坐标；原点和定义域需要单独检查。

eigenvalues线性代数

特征值

返回矩阵的特征值列表，可继续用于对角化和矩阵函数。

04 / 安装

两个文件，
必须成对。

从同一次 Release 下载同一语言的 G3A 与 AC2，再复制到 fx-CG50 存储根目录。

打开 Releases ↗
  1. 01下载选择 khicas-zh 或 khicas-en-baseline 构建产物。
  2. 02配对ZH 使用 khicaszh.g3a + khicaszh.ac2；EN 使用 khicas50.g3a + khicas50.ac2。
  3. 03复制把两个文件一起复制到计算器存储根目录，覆盖前先备份旧版本。
  4. 04启动从主菜单运行对应语言版本；出现加载错误时，先确认两个文件来自同一次构建。
